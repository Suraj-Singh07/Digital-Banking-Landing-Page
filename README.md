# Digital Banking Landing Page 💳

A modern and responsive digital banking landing page designed to provide a clean, professional, and user-friendly banking experience.

[View Live Website](#)

## 📌 About The Project

This project is a frontend landing page for a digital banking platform. It focuses on creating a modern banking interface with a responsive layout, clean typography, attractive visual elements, and intuitive navigation.

The project was created as part of my frontend development learning journey to practice building real-world website layouts using HTML and CSS.

## ✨ Features

* Modern digital banking UI
* Responsive design for desktop, tablet, and mobile devices
* Clean and structured layout
* Hero section with call-to-action
* Banking services/features section
* Interactive hover effects
* Responsive navigation
* Mobile-friendly layout
* Clean footer section

## 🛠️ Technologies Used

* HTML5
* CSS3
